
## Design skills reminder

The user often forgets which skills are installed. When a request fits one, name it and use it without waiting to be asked:

- UI layouts, design systems, styling: `ui-ux-pro-max`, `frontend-design`
- Animation and motion: `animate`, `review-animations`, `improve-animations`, `find-animation-opportunities`, `apple-design`, `emil-design-eng`
- Mobile web feel: `mobile-native`; React Native: `animate-expo`
- Stress-testing UI: `break-ui`
- App Store / Play Store images: `app-store-screenshots`
- Planning, debugging, reviews: `superpowers` skills (brainstorming, writing-plans, systematic-debugging)
